# Changelog

What changed in each version of Wishlist Grid View for PriceCharting.

## 1.4.6 — 2026-11-15

### Changed
- Removed the "Export CSV" button from the Select/Exclude panel.

## 1.4.5 — 2026-11-15

### New
- The blue box above the list now always shows your wishlist's item count and total value, plus loading progress and a Retry button when needed.

### Changed
- List view: the Move button now reads "Move" ("Confirm?" after the first click).
- List view: the Remove button matches the other buttons and is stacked above Move at the same width.

### Fixed
- The blue box no longer disappears a few seconds after the page loads.

## 1.4.4 — 2026-11-15

### Changed
- List view: the Move button now sits under the Remove button at the start of each row, instead of at the far end.

## 1.4.3 — 2026-11-15

### New
- Move to collection is now available in list view too (click once, then again to confirm), not just grid view.

## 1.4.2 — 2026-11-15

### New
- If a wishlist page fails to load, a Retry button picks up from the page that failed.

### Fixed
- Cards that appeared twice when prices tied across page boundaries are now shown once.
- Cards that show up after the page has loaded now get the Select/Exclude/Move buttons and are sorted into place.
- A failed load no longer breaks PriceCharting's own scrolling or leaves some cards without larger grid images or the Remove label.

## 1.4.1

### Fixed
- Duplicate, button-less cards no longer appear at the top of the list when you scroll while the wishlist is loading.

## 1.4.0 and earlier

Whole-wishlist price sort, grid view, item count and total value, search, Select/Exclude lists, grid-view Move to collection, a labeled Remove button, and the "Type part of set" filter hint.
